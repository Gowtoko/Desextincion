# Sitio Web: Desextinción y Biotecnología Animal

Proyecto web estático generado a partir del documento *Desextinción: Fundamentos Biotecnológicos, Alcances y Casos de Estudio*.

## Estructura de archivos

- `index.html`: Estructura semántica completa con las 5 secciones del documento (Concepto y pilares, Postura UICN, Desafíos/Beneficios/Riesgos, Casos de estudio y Fuentes bibliográficas).
- `css/styles.css`: Hoja de estilos responsiva con diseño moderno inspirado en biotecnología y conservación.
- `js/main.js`: Interactividad para navegación móvil y filtrado dinámico de la matriz de análisis (Desafíos, Beneficios y Riesgos).

## Uso

Abre `index.html` directamente en cualquier navegador web moderno.
